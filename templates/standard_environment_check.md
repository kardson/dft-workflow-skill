# 标准工作流完整环境检查

由 agent 填写，用户无需手填。覆盖完整标准工具链，复用实际版本、路径及已有验证记录。未验证写“待核实”；已安装不等于功能已验证。每项附证据与核实日期。

| 项目 | 必须核实的内容 | 结果与证据 | 缺项处理 |
|---|---|---|---|
| VASP | 实际可执行文件、版本及标准流程所需程序 | 待核实 | — |
| 编译功能 | 实际 VASP 的 HDF5 输出支持；核对构建记录或同一可执行文件的真实输出证据 | 待核实 | — |
| MPI 与运行库 | 实际启动器、动态库解析、与 VASP 的运行兼容性 | 待核实 | — |
| VASPKIT | 版本、调用路径，标准输入准备与势处理接口 | 待核实 | — |
| Python 与科学依赖 | 实际解释器；numpy、ASE、pymatgen、matplotlib 及依赖兼容性 | 待核实 | — |
| 附加分析依赖 | custodian、py4vasp、sumo、MacroDensity 及所需依赖，完整覆盖标准工具链 | 待核实 | — |
| 标准工具入口 | 输入生成、实际文件检查、结果解析及分析入口可调用 | 待核实 | — |
| 执行与取证 | 连接、标准启动脚本、工作站状态记录、按需读取与原始输出回收接口 | 待核实 | — |
| 赝势库 | 版本族、来源和可访问性；所需组件齐全，不记录许可文件内容 | 待核实 | — |
| CPU 与并行资源 | 可用物理核心、内存，运行脚本资源声明与可用资源匹配 | 待核实 | — |
| 存储与目录 | 可用容量、工作目录、读写权限，保留已有数据 | 待核实 | — |

缺项处理明确填写“安装”“配置”“重新编译”或“补验证”及具体原因。仅从历史路径存在不能确认功能通过；编译来源未证实与运行功能缺失分别记录，避免无依据重编译。

## 给用户的简明结论

- 核实日期：待填。
- 标准工作流环境：完整 / 存在缺项 / 待核实。
- 具体缺项及处理：待填。
- 证据位置：待填。

仅全部必需项目有有效证据时给出“完整”。环境不变时复用已有检查；环境或标准功能变化时仅补查受影响项。硬件满足特定计算规模的判断在方案阶段补充，不能由完整安装推断。

检查默认只读。轻量验证不启动科研计算；需要安装、重编译、部署或新计算验证时，沿用已有权限与批准范围。本模板不创建 agent 持续轮询或定时任务。
