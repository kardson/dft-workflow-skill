# 计算结果审阅

## 先给研究者看的结论

- **回答的问题：**
- **结论（一至三句）：**
- **结果可信到什么程度：** 适用 / 有条件适用 / 证据不足；用日常语言解释原因。
- **这份结果能支持什么判断：**
- **这份结果还不能说明什么：**
- **建议的下一步：** 一项明确动作或“目前无需新增计算”；注明负责人和授权状态。

## 依据与核对

- **任务、尝试和实际执行身份：**
- **实际使用的结构、设置及来源：** 链接到最终实际输入和批准规格。
- **执行状态：** 启动证据、结束方式、原始输出位置；运行中、正常退出和完成科学审阅须分开写。
- **主要数值和单位：** 给出直接支持结论的主输出路径、段落/字段或图表。
- **收敛检查：** 相关的电子、几何和数值收敛证据；不适用项说明原因。
- **对照是否可比：** 模型、方法、赝势或能量基准有差异时说明影响；不可直接比较的数值不要合并排序。
- **警告、冲突和缺失：** 如实写明，包括无法判断的部分；未知不写成通过或失败。
- **结论用途：** 适用于哪一个具体问题或比较；未通过的科学门槛仍保持未通过。
- **审阅裁决：** 接受（限定用途）/ 条件接受 / 整改 / 证据不足 / 不接受；审阅人、日期和记录链接。

## 面向非专业读者的检查

交付前确认正文能让读者用几句话回答：研究人员原本想知道什么、这次实际观察到了什么、哪些证据支撑解释、还存在哪些限制、下一步由谁决定。若必须先读工具日志才能理解结论，应补写通俗解释并保留日志链接。
