# 更新技能并保留本地适配

不要覆盖正在使用的安装目录。将可信来源的新版本下载到独立候选目录，调用 tools/skill_upgrade.py --help，指定 --candidate、--installed、--destination（全新独立目录）。工具只按候选 manifest 白名单复制并核对内容身份，拒绝越界、重复和链接路径。manifest 身份不是发布者签名；候选来源可信性仍需确认。

升级目录包含 skill/ 和 upgrade.json；默认 local-adapter.md（其他文件用可重复的 --preserve 明确指定）备份到 preserved-local/，不会混入公开清单。旧安装完全保留，因此其他本地配置与定制入口也保留原处；agent 必须对比旧 SKILL.md、本地适配和其他自定义文件，不能假定自动备份覆盖所有定制。不要把私人适配上传公开仓库。

升级状态固定 STAGED_NOT_ACTIVATED、兼容性 UNVERIFIED。先在新包检查 skill 格式、路径和相关工具，复用有效环境证据，变化时补查。经过审阅和用户切换授权后，用宿主支持的方式切换技能发现；重建本地适配链接，保留旧安装与恢复路径。支持的宿主切换操作尚需具体适配，不声称复制文件已经完成激活。

已有计算沿用原执行身份、原始批准和原工具，不迁移、不重复提交。新任务可采用经验证的新版本。若新版本不兼容，保留候选供诊断、继续旧版，不清理旧记录。
