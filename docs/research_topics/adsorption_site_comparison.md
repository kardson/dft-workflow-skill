# 吸附位点比较：待路线采用的专题指南

状态：工程指南与交接模板，不是某个材料的已批准科研方案。实际采用、方法、来源、判据及计算仍由原路线确认；本指南不触发生成或提交。

## 研究定义

先明确目标是几何筛选、同组成位点总能比较、固定几何相互作用，还是带指定参考态的吸附能。后两者不能互相改称。明确吸附物、基底、晶面、终止/重构、覆盖度、钝化及伪氢标签、晶胞/真空、约束、外场、旋轨/自旋、功能泛函与PAW环境。未决项留在intake和方案，不填通用数值默认。

## 结果与停止条件

每个候选列实际来源、几何、执行身份、收敛证据、能量定义/数值及限制。缺失输出、错身份、未收敛或方法不相容时，不生成正式能量排序。近简并判据和进一步检查由批准方案明确，不采用通用差值阈值。若位点在弛豫中改变，应先由路线判定位点归属与比较意义，不凭目录名认定仍是原位点。

完整吸附能若需要现有reference入口之外的参考态、零点/热修正、带电体系或特殊外场处理，保留能力缺口；不得以固定几何差值或MLIP预测代替。本指南不选择这些科学方法，也不修改现有收敛、厚度、闭合循环及外场门槛。

## 工程预演与实际采用

工程预演只用明确的合成输出验证“问题→事实→观察/解释→证据索引→多格式报告”链路。虚拟批准和数值不作为科研证据。实际采用时由路线补齐问题、来源、比较合同、判据和授权；所有生产记录仍由原写入者维护，不批量迁移历史任务。
