# 用户体验功能与验证范围

本页区分工具实现、合成测试与真实计算证据。不承诺所有宿主环境兼容，不据此声称科研节时或科学准确率。

| 能力 | 已有验证 | 边界 |
|---|---|---|
| 首次接入 | 缺环境报告与宿主能力依据时保持未知并交付问题清单；已有工具报告接入实测 | 不把历史报告视为当前工作站完整环境 |
| 异常交付 | 研究澄清、方案、准备、执行、回收、分析的统一问题报告 | 报告格式不代替证据审阅 |
| 已有计算导入 | 实际科学解析器对合成OSZICAR完成部分解析；失败/摘要冲突/副本变化拒绝 | 不补造历史批准，不据单个能量判断稳定性 |
| 任务恢复 | 准备—回收—分析合成链，来源变化阻断；任务卡子区块保留历史 | 恢复历史状态不代表实时计算状态 |
| 升级 | 实际本地技能升级准备、私有适配保留、备份及本地激活 | 宿主发现/刷新能力有差异，旧任务不迁移 |
| Linux SSH 监督器 | 真实Linux/Python/tmux中，独立目录合成包上传、短时Python子进程及一次终态读取；退出0但缺输出判失败，文件/标记齐全判待审阅 | 未调用VASP或读取赝势，不证明完整固定胞prepare/launch链或真实DFT计算 |
| 固定胞 fresh 真实链 | 两原子工程测试经生成/审计/SSH部署/远端准备启动，终态输出完整回收，实际XML解析报告电子收敛；真实进程继承受限cgroup/亲和/优先级 | 单个工程样例；参数解释仍需审阅，不推及warm包、科学精度或生产就绪 |
| 受限测试资源 | 实际cgroup父子继承和节流、真实MPI rank亲和、独立tmux内校验及实际VASP进程限额 | 未证明所有宿主可用，未完成墙钟终止故障注入；共享CPU不保证零影响 |

公开候选已通过整包回归；当前Windows验证有4项因目录符号链接权限跳过，不能记为已验证。具体数量、候选身份及后续接口修订以对应维护验证记录为准。发布守卫核对文件清单、语法、依赖与已知公开内容边界，并非科学正确性证明。

维护过程的真实私有日志和工作站配置不随公开包发布。上述概述不替代外部用户在实际环境完成核验。Linux SSH适配器仍处于全链验证未完成状态，不应宣称生产就绪。详见[部署适配说明](ssh_deployment.md)。
