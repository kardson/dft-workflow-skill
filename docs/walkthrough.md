# 一次自然语言协作示意

以下是对话示意，不是实测计算记录，也不提供可直接用于科研的参数或能量。

**用户：** 我有两个候选结构，想比较哪个更稳定。

**Agent：** 请确认材料组成、比较条件、结构位置和希望判断的范围。我会先核对已有环境和材料；缺少的方法与参照需要讨论，不能仅比较两个未经核查的能量。

**用户：** 我提供结构和已有文献；先提出方案，不运行。

**Agent：** 整理已确认问题、材料来源及缺项。给出模型、方法、收敛与可比要求、计算顺序、资源估计依据和停止条件；未知代价明确标出。当前交付是待确认方案。

**用户：** 确认方案，允许在指定工作站和目录执行这一批任务。

**Agent：** 记录实际批准范围，准备输入并检查；若部署尚未适配，先说明缺口，不声称已提交。适配与执行条件通过后，在授权范围内启动，以真实推进证据交付启动回执，并结束本轮。

**用户（稍后）：** 现在算完了吗？

**Agent：** 进行一次状态查询，报告观察时间和证据。仍运行或未知就说明后结束；已结束才按授权回收输出。不会因启动计算自动持续盯守。

**Agent（取得输出后）：** 核对来源、实际设置、收敛与比较条件，交付事实、解释、限制和证据链接。失败或证据不全时说明下一步；不能用正常退出代替科学接受。

**用户：** 审阅结果，决定接受、补证或讨论新方案。

你无需填写 JSON 或记住脚本名；agent 负责记录和调用。上述每个完成状态必须由实际证据支持，不能把这份示意当作执行回执。
